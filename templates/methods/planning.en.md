**What it solves**: Without planning, the model can only keep continuing paragraph by paragraph. The main plot drifts the longer it runs, pacing is slack early and rushed late, and foreshadowing gets planted but never paid off. The whole book also doesn't fit in the context, so later chapters overturn settings established earlier. Planning separates "what to write" from "how to write it": fix the skeleton first, then have the model fill in the prose along it.

**Common designs**

1. **Layer-by-layer expansion**: one-sentence premise → characters and setting → plot by act or volume → scenes → prose. Each layer's output is the next layer's input, and the author can edit any layer before generating further down. Many projects organize these layers with the Snowflake Method. Examples: [Dramatron](https://github.com/google-deepmind/dramatron), [GOAT-Storytelling-Agent](https://github.com/GOAT-AI-lab/GOAT-Storytelling-Agent), [AI_NovelGenerator](https://github.com/YILING0013/AI_NovelGenerator)
2. **Several candidates at the planning layer, keep the best**: generate several candidates at the outline stage and pick one using model self-evaluation, a trained reranker, or programmatic criteria. Pacing uses a concreteness evaluator to keep nodes on the same layer at the same level of detail. Examples: [gpt-author](https://github.com/mshumer/gpt-author), [doc-story-generation](https://github.com/yangkevin2/doc-story-generation), [AI-automatically-generates-novels](https://github.com/wfcz10086/AI-automatically-generates-novels), [Pacing](https://github.com/YichenZW/Pacing)
3. **Rolling planning**: detail only the next few chapters and keep the distant parts as a rough outline. Expand them when the writing gets there, using summaries of what has been written and the current character states. RecurrentGPT shrinks the unit to the paragraph: each step writes one paragraph of prose, then the plan for the next one. Examples: [RecurrentGPT](https://github.com/aiwaves-cn/RecurrentGPT), [ainovel-cli](https://github.com/voocel/ainovel-cli), [DOME](https://github.com/Qianyue-Wang/Generating-Long-form-Story-Using-Dynamic-Hierarchical-Outlining-with-Memory-Enhancement), [long-novel-generator](https://github.com/jiaw-Zh/long-novel-generator)
4. **Chapter contracts**: before each chapter, generate a structured card listing the goal, obstacles, beats, required elements, foreshadowing IDs, the end-of-chapter hook, and things not allowed. After writing, a program checks the chapter against the card; if it fails, the chapter is rewritten with the feedback. In short drama the same thing is called the episode list, with each episode marked with its hook type and paywall points. Examples: [InkAI](https://github.com/yan2959088709/InkAI-), [agent-novel](https://github.com/RTY798/agent-novel), [dsh-novel-forge](https://github.com/huangziyuan-general/dsh-novel-forge), [short-drama](https://github.com/0xsline/short-drama)
5. **Stage gates**: split the workflow into fixed stages, each with a defined output. If a required earlier output is missing or not confirmed, the next stage does not start; some projects decide this with a script or a state file. Many projects copy Spec Kit's seven steps: "constitution → specification → clarification → plan → tasks → writing → analysis". Examples: [novel-writer](https://github.com/wordflowlab/novel-writer), [speckit-preset-fiction-book-writing](https://github.com/adaumann/speckit-preset-fiction-book-writing), [short-drama-scriptwriter](https://github.com/SumOneHK/short-drama-scriptwriter)

**Trade-offs and pitfalls**

- **Too much outline makes the model jump ahead.** Once the model knows the ending, it rushes toward it. [ai-novel-writer](https://github.com/KKKenChow/ai-novel-writer) splits the book's progress into six stages and widens how much of the outline is visible step by step, then checks generated text for keywords from later chapters. dsh-novel-forge takes the full profiles of characters who carry a mystery out of the context.
- **Gates written into the prompt get skipped.** dsh-novel-forge's principle is "code enforcement > prompt self-discipline": if the detailed outline has not been approved, the chapter-writing tool refuses outright. Projects that control the workflow only through prompts depend on the host cooperating. [ultimate-novel-creation-skill](https://github.com/Fly143/ultimate-novel-creation-skill), for example, requires you to first set its system_prompt.md as the host's system prompt.
- **The outline will change sooner or later.** When any chapter outline changes, [jarvis-write](https://github.com/ynnyh/jarvis-write) analyzes the downstream impact, lets the author tick which chapters to regenerate in cascade, and marks already-written prose as out of sync. ainovel-cli lets you add notes in the middle of writing, assesses what they affect, and rewrites the affected chapters.
- **The finer the layers, the more the prose feels like filling in blanks.** In Dramatron's user study, screenwriters found the output formulaic and preferred to use it for finding ideas and building the world. The README also admits that top-down hierarchical generation does not match how everyone writes. At key decision points agent-novel first offers three options for the author to pick from, so the model does not always take the easiest path.
- **Candidates and steps both cost money.** Branching into several candidates at every layer and running a dozen or more steps per chapter multiplies token use. [novel_writer_agent](https://github.com/nonever2109/novel_writer_agent) runs about 20 workflow steps per chapter.

**Where to start**: [GOAT-Storytelling-Agent](https://github.com/GOAT-AI-lab/GOAT-Storytelling-Agent) is good for first understanding the skeleton of hierarchical planning: one code snippet in its README chains the whole flow from book setup to scene-by-scene writing. [agent-novel](https://github.com/RTY798/agent-novel) suits human-AI co-writing of long novels in Claude Code or Codex: chapter cards plus author confirmation of key choices, with a light workflow. [ainovel-cli](https://github.com/voocel/ainovel-cli) suits people who want to run a long novel fully automatically; look closely at its rolling volume-arc planning and step-level checkpoint recovery.
